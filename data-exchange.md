# Data Exchange

> Monthly input file spec and payroll outputs for platforms: CSV and JSON fields, payroll register, GL journal, payslips and F24 summary.


<section> <span class="eyebrow">Data exchange</span> <h1 id="one-input-file-in-five-outputs-back">One input file in, five outputs back</h1> <p class="lede">Send one file per period as CSV (UTF-8, comma separated, header row) or JSON array, by SFTP or REST API. Each line is one event for one employee. Field names below are the defaults; we can map yours.</p> </section> <section> <h2 id="monthly-input">Monthly input</h2> <div class="tbl"><table> <thead><tr><th>Field</th><th>Type</th><th>Notes</th></tr></thead> <tbody><tr><td class="code">partner_employee_id</td><td class="code">string</td><td>Your ID for the employee. Key for every record.</td></tr><tr><td class="code">period</td><td class="code">YYYY-MM</td><td>Payroll month.</td></tr><tr><td class="code">record_type</td><td class="code">enum</td><td>hire, change, leave, variable, termination</td></tr><tr><td class="code">effective_date</td><td class="code">YYYY-MM-DD</td><td>Date the event applies from.</td></tr><tr><td class="code">first_name, last_name</td><td class="code">string</td><td>Hires only.</td></tr><tr><td class="code">tax_code</td><td class="code">string(16)</td><td>Italian codice fiscale.</td></tr><tr><td class="code">birth_date</td><td class="code">YYYY-MM-DD</td><td>Hires only.</td></tr><tr><td class="code">email</td><td class="code">string</td><td>Payslip delivery and contact.</td></tr><tr><td class="code">iban</td><td class="code">string</td><td>Net pay account.</td></tr><tr><td class="code">address, city, postal_code, province</td><td class="code">string</td><td>Residence;
